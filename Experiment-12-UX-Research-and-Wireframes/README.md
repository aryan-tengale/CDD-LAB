# Experiment 12 — User Personas, User Journeys and Wireframes

## Aim
Design user personas, a user journey map, and low-fidelity wireframes for a chosen application idea.

## Requirements
Pen and paper, whiteboard, or an optional design tool such as Figma or Miro. No software installation is required.

## Procedure

### 1. Choose an application idea and target users
Choose a simple application (the manual uses a food delivery app as an example). Identify two or three distinct user segments.

### 2. Create two personas
Create a realistic persona for each segment. Include:
- Name, age, and occupation
- Goals
- Frustrations
- Typical behavior
- A short representative quote

Personas should reflect specific goals and frustrations, rather than generic descriptions. If research is simulated for the lab, make that clear.

### 3. Map one user journey
Choose a goal for one persona (for example, ordering dinner after work). For each stage, document:
- Stage
- User action
- Thoughts
- Emotion
- Pain point
- Opportunity for improvement

The manual's example stages are Awareness, Consideration, Decision, Action, and Post-use.

### 4. Sketch low-fidelity wireframes
Sketch at least three key screens, such as Home, Restaurant Detail, and Cart/Checkout. Use simple boxes, lines, and placeholder text; do not add final colors, typography, or polished imagery at this stage.

### 5. Annotate and review
Add short notes explaining the function of key elements (for example, how a search bar filters results). Exchange wireframes with a peer and record feedback about clarity, missing elements, and usability.

## Deliverables
- Two user personas with realistic goals and frustrations
- One complete user journey map for a persona's goal
- Low-fidelity wireframes for at least three screens
- Annotations and peer feedback

## Key concepts
Persona, user journey, wireframe, empathy map, and pain point. A wireframe shows structure; a mockup is styled and static; a prototype simulates interactions.

## Observation checklist
- [ ] Two personas created
- [ ] Journey includes actions, thoughts, emotions, pain points, and opportunities
- [ ] Three or more low-fidelity screens sketched
- [ ] Wireframes annotated
- [ ] Peer feedback recorded
