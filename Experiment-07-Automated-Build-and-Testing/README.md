# Experiment 7 — Automating Build and Testing with GitHub Actions

## Aim
Automate an application's build and test process using GitHub Actions, including a matrix build and status badge.

## Requirements
GitHub repository, Node.js/npm (or Python/pip), and a test framework. This repository uses Node.js and Jest, matching the lab manual's example.

## Procedure

### 1. Install Jest and define a test
```bash
npm install --save-dev jest
```

Ensure `package.json` has the test script:

```json
"scripts": {
  "start": "node index.js",
  "test": "jest"
}
```

Create `sum.js`:

```javascript
function sum(a, b) { return a + b; }
module.exports = sum;
```

Create `sum.test.js`:

```javascript
const sum = require('./sum');

test('adds 1 + 2 to equal 3', () => {
  expect(sum(1, 2)).toBe(3);
});
```

### 2. Run tests locally
```bash
npm test
```

Confirm the test passes before pushing.

### 3. Inspect the workflow
The `.github/workflows/build-test.yml` workflow:
- Runs on pushes and pull requests targeting `main`.
- Uses a matrix of Node.js versions 18 and 20.
- Installs dependencies, runs the build command if present, and runs Jest tests.

### 4. Commit and push
```bash
git add .
git commit -m "Add automated build and test workflow"
git push origin main
```

Open **Actions** and verify that two matrix jobs run, one for each Node.js version.

### 5. Demonstrate a failing test
Temporarily change the expected result in `sum.test.js` to an incorrect value, commit, and push. Inspect the failed assertion in the Actions log. Restore the correct expectation, commit, push, and verify success.

### 6. Add a status badge
In GitHub Actions, open the workflow's menu and choose **Create status badge**. Copy the Markdown snippet GitHub provides and add it near the top of the repository README. Use the actual repository and workflow URL generated by GitHub.

## Common issues
- Cannot find Jest: install it as a dev dependency and ensure dependencies are installed in Actions.
- CI differs from local: check committed files and environment variables; do not commit `node_modules`.
- Matrix failure on one version: inspect that version's job log for compatibility issues.

## Observation checklist
- [ ] Jest installed and test passes locally
- [ ] Build and test workflow runs
- [ ] Both Node.js matrix jobs observed
- [ ] Failing test detected and fixed
- [ ] Status badge added using GitHub's generated URL

## Result
Add the Actions run evidence and final badge after completing the workflow.
