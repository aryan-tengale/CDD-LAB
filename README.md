# CDD Laboratory

**Course:** Collaborative Development and DevOps (1BCS303)

This repository contains selected laboratory work based on the course laboratory manual.

## Experiments included

| Experiment | Title |
|---|---|
| 1 | Installation and configuration of Git; local repository and basic Git operations |
| 2 | Git clone, push, pull, fetch and repository synchronization |
| 3 | Branching, merging, rebasing and resolving merge conflicts |
| 4 | GitHub repositories, issues, forks, pull requests and code reviews |
| 5 | Team collaboration using GitHub repositories and branching strategies |
| 6 | Continuous Integration workflows using GitHub Actions |
| 7 | Automating build and testing using GitHub Actions workflows |
| 12 | User personas, user journeys and wireframes |
| 13 | High-fidelity UI prototypes and reusable components using Figma |

**Scope note:** Experiments 8–11 (Docker) and Experiment 14 (Mini Project) are intentionally excluded.

Each experiment folder will contain its procedure, relevant commands or design artefacts, and an observation checklist. Screenshots and results should be added after the corresponding activity is actually performed.

## Notes

- Follow the experiment instructions and expected results in the official laboratory manual.
- Replace sample names, email addresses, repository URLs and student details with your own where required.
- Do not commit passwords, access tokens, API keys or other secrets.
- GitHub Actions workflows are stored under `.github/workflows/` where applicable.
